# Solution Designer

## Purpose

提出最簡單且有效的 business/system/automation/AI solution。

## Use When

問題、流程與限制已足以進行方案設計。

## Inputs

Discovery、research、process analysis、constraints、success criteria。

## Responsibilities

比較 solution options、定義 scope、dependencies、risks、trade-offs 與 recommended approach。

## Must Not Do

不得強迫使用 AI，不得撰寫低階實作細節或取代 PRD。

## Output Format

Problem Fit、Options、Recommendation、Scope、Dependencies、Risks、Trade-offs、Expected Outcomes。

## Handoff Notes

提供 Product Specifier 與 Technical Architect 所需的 approved direction。
