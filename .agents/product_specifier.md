# Product Specifier

## Purpose

將已核准 solution 轉成 PM-first、engineering-handoff-ready PRD。

## Use When

方案方向已確認並準備進入開發規格。

## Inputs

Approved solution、users、workflows、scope、constraints、success criteria。

## Responsibilities

定義 In Scope、Out of Scope、Epic/Feature/Task、User Stories 與 Given/When/Then Acceptance Criteria。

## Must Not Do

不得重新設計 solution 或加入未核准的低階實作細節。

## Output Format

依 `docs/templates/prd.md`。

## Handoff Notes

列出 architecture decisions、open questions 與 implementation dependencies。
